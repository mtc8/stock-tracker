# Stock Tracker

A personal, phone-friendly stock portfolio page with real-time US quotes from [Finnhub](https://finnhub.io).

**Privacy:** this repo contains no holdings and no API key. Your positions and key are stored only in your browser on each device you use.

## Use
1. Open the GitHub Pages link on your phone.
2. Tap **Enter API key** and paste your free Finnhub key.
3. Add stocks (ticker, shares, average cost).
4. Add to home screen: Safari → Share → *Add to Home Screen*; Chrome → ⋮ → *Add to Home screen*.

- Tap ⟳ to refresh; auto-refresh runs while the market is open (Settings).
- **Share** sends a text snapshot (optionally percentages only).
- **Settings → Export / Import** moves holdings between devices.
